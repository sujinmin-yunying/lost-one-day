# 《消失的那一天》GitHub Pages 修复版（本地个人模式）

## 这版修复了什么
- 恢复 8 个论坛版块、原有示例帖子、回复、调查线索、推理笔记和结局档案。
- 未登录时也能浏览帖子和版块，不会再因为没有登录服务而把首页内容全部挡住。
- 注册/登录改为浏览器本地账号，不需要创建 Supabase 项目。
- 登录后可发帖、回复、点赞、收藏、记录调查线索和推理；这些数据只保存到当前浏览器。

## 重要限制
- 这是**本地个人模式**，不是云端安全账号系统。账号和数据只存在当前浏览器；清理浏览器网站数据、换浏览器或换设备，账号/帖子/进度不会同步，可能无法找回。
- 密码会在本地进行摘要处理，但这不等于专业的服务器端身份验证。请不要使用重要网站的密码，也不要把它用于敏感内容。
- GitHub Pages 网站本身是公开可访问的；本地账号只用于本机区分个人进度，不会阻止其他人访问公开网页或阅读内置示例帖子。
- 若将来希望真正的邮箱验证、跨设备账号登录，才需要接入 Supabase 等认证服务；本版本不依赖它。

## 更新到 GitHub（无需写代码）
1. 打开仓库： https://github.com/sujinmin-yunying/lost-one-day
2. 点击文件列表中的 `index.html`。
3. 点击右上方铅笔图标（Edit this file）。
4. 先确认打开的是仓库根目录的 `index.html`，不要编辑旧的子文件夹版本。
5. 在编辑页面按 `Command + A`（Mac）全选旧内容。
6. 打开修复包里的 `index.html`，用文本编辑器打开并全选复制全部内容，粘贴覆盖 GitHub 编辑器中的旧内容。
7. 页面底部找到 **Commit changes…**，点击后再点确认提交（Commit changes）。
8. 等待约 1–5 分钟，打开 https://sujinmin-yunying.github.io/lost-one-day/ ，再按 `Command + Shift + R` 强制刷新。

## 推荐测试顺序
1. 未登录时：确认首页显示帖子、版块和搜索，点击版块和帖子标题。
2. 点击「登录 / 注册」→「没有账号？注册」，输入邮箱和至少 6 位密码。
3. 注册后测试发帖、回复、收藏、调查笔记和推理题。
4. 退出登录后重新登录，确认刚才的内容仍在当前浏览器。

## 如果更新后仍显示旧页面
- 等几分钟再强制刷新：`Command + Shift + R`。
- 检查 GitHub 仓库根目录 `index.html` 的提交时间是否刚刚更新。
- 访问 GitHub 仓库的 **Actions**，确认 Pages 发布流程完成。
